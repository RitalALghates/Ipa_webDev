# Ipa_webDev

The Cat API Viewer: a small web project that uses [TheCatAPI](https://thecatapi.com/) to fetch and display cat images.

## Features

- Search cats by breed
- Show random cats
- Interactive UI feedback
- Error message when the search is submitted empty

## Files

- `index.html` - page structure
- `script.js` - API calls and UI logic
- `style.css` - styles

## Run

Open `index.html` in a browser.
